# 🎬 CineScope

CineScope is a responsive TV show discovery application built with Next.js and TypeScript.

## ✨ Features

- Browse TV shows
- Search for shows
- Filter shows by genre
- Sort shows by rating and name
- View show details
- Manage favorite shows
- Responsive UI for desktop and mobile
- Sign-in and sign-up forms with validation

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios
- TanStack Query
- React Hook Form
- Zod
- TVMaze API

## 🔐 Authentication

The project includes sign-in and sign-up interfaces with form validation.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/alisafaei7811-blip/CineScope.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 API

TV show data is provided by the [TVMaze API](https://www.tvmaze.com/api).
